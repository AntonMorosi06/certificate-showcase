# Publication Notice

This repository is a public certificate showcase by Anton Morosi.

The repository is intended to present selected educational and professional credentials as part of a portfolio. Certificate images, text, layout, descriptions, and presentation assets are not open source and are not free to reuse.

## Privacy boundary

Only curated public-facing certificate assets should be stored here.

Do not publish:

- identity documents;
- private administrative documents;
- certificates containing unnecessary personal codes;
- full verification codes if they are not intended for public sharing;
- addresses, phone numbers, signatures, private emails, or scans with sensitive metadata.
